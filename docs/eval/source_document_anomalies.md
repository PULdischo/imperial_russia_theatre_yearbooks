# Confirmed source-document anomalies

This is a different catalog from `known_issues.md`: that file tracks
problems with *this project's extraction pipeline* (model misreads, prompt
ambiguities, code bugs). This file tracks the opposite finding — cases
where the transcription (both the model's and, after a source check, ours)
is confirmed **correct**, and the discrepancy is a property of the original
1890–1908 printed yearbook itself: a performance tally whose components
don't sum to its own stated total, as actually printed.

`outputs/` is gitignored and disposable (regenerated by re-running the
pipeline) — these findings only survive if they're written down here, so
this file is the durable record. Companion working file (not committed):
`outputs/full_run/credit_mismatch_review.csv`, which tracks the full
in-progress review (source errors, model errors needing correction, and
not-yet-checked entries) that this file's source-error rows are drawn from.

## Method

Each row below was checked directly against the scanned source page (300
DPI render of the original PDF) — not inferred from the extracted data
alone. "Printed as" shows exactly what's on the page; the arithmetic is
verifiable by anyone re-checking against the same scan.

## TheaterSchoolReport vs. BalletArtists roster: graduate service-start dates disagree by exactly one month for at least two full cohorts

Unlike the arithmetic mismatches above (one printed number vs. another,
same document), this is a disagreement **between two different printed
documents** about the same fact: when a graduating class entered Imperial
service. The Theater School Report states the class's official
appointment date; the BalletArtists roster (printed independently, every
season for the rest of each dancer's career) states a different date for
the same event.

| cohort | Report says | BalletArtists says (repeated every season on record) | source |
|---|---|---|---|
| St. Petersburg, graduated spring 1897 (7 people incl. Ваганова, Агриппина) | "съ 1-го мая 1897 года" (1 May 1897) | "1 іюня 1897 г." (1 June 1897) — identical across all 11 seasons Ваганова appears, 1897-98 through 1907-08 | `pdf/Spiski_Graduates/ForUpload_1896-97_TheaterSchoolReport.pdf`, p.1 (verified directly against the scanned page — this is not a transcription artifact on either side) |
| St. Petersburg, graduated spring 1898 (14 people incl. Галка, Ольга) | "съ 1-го мая 1898 года" (1 May 1898) | "1 іюня 1898 г." (1 June 1898) — identical across all 10 seasons Галка appears, 1898-99 through 1907-08 | `pdf/Spiski_Graduates/ForUpload_1897-98_TheaterSchoolReport.pdf`, p.1 (text-level match to the same pattern; this specific page image not independently re-viewed) |
| St. Petersburg, graduated spring 1892, individually assigned to the Moscow troupe (Бекъ, Константинъ) | "съ 1-го іюня 1892 г." (1 June 1892) | "1 сентября 1892 г." (1 September 1892) — identical across all 15 seasons he appears, 1892-93 through 1907-08 | `pdf/Spiski_Graduates/ForUpload_1891-92_TheaterSchoolReport.pdf`, p.0 (verified directly against the scanned page). Same shape as the two rows above but a 3-month gap rather than 1 month, and involves a graduate transferring cities (his own class's other 17 graduates all entered the St. Petersburg troupe on the June date the Report gives) |

Both readings are internally consistent and well-attested on their own
side — the Report's "мая" is unambiguous and legible on the page, and
the BalletArtists date is corroborated by a decade of identical repeated
printings, not a one-off. Neither looks like a plausible OCR/model
misread of the other (мая/May and іюня/June don't resemble each other).
Likely explanation, offered without certainty: the Report may record the
*official appointment order* date, while the roster records when the
dancer's *paid service* actually began — a month's administrative gap
between the two would not be unusual for a state institution, but this is
a historian's question, not a data one.

**Practical consequence**: `outputs/full_run/ballet_graduates_tenure.csv`
(docs/eval/known_issues.md #34) sources tenure start dates from the
Theater School Report as primary, per instruction, and flags every row
where the BalletArtists roster disagrees rather than silently picking one.
The cross-check now covers both `report_per_row` (originally 222 rows)
and `report_hand_verified` (148 rows, added later in the same effort) —
28 rows total are flagged: the 22 from the two confirmed May/June
cohorts plus Бекъ above, plus individual cases at varying confidence —
some (like Бекъ) a genuine, consistently-repeated same-person
discrepancy; others (Тихомировъ, Владиміръ, a 6-year gap on only 2
BalletArtists seasons; Ивановъ, Александръ, a 10-year gap on a single
season; Усачевъ, Александръ, similarly) far more likely a same-named but
unrelated person than the same dancer, given common Russian surnames and
an implausibly large date gap. Flagged either way rather than silently
resolved, per the project's standing rule against guessing through
name-collision ambiguity.

One apparent disagreement in this same batch turned out **not** to be a
disagreement at all, and is worth recording as a caution about this
whole cross-check method: Тихомировъ, Василій (1892-93) was flagged as a
3-month Report-vs-BalletArtists gap, but that was a parsing bug, not a
real discrepancy — his own `tenure_note_text` is one sentence covering
both his cohort's default date *and* a named individual exception for
him specifically ("...кромѣ ученика Тихомирова, который зачисленъ съ
1-го сентября 1893 года въ Московскую балетную труппу"), and the
date-parser had taken the cohort default instead of his own named
clause. Once corrected to the date his own row's text actually names for
him, Report and BalletArtists agree exactly (both 1893-09-01, Moscow).
Found while identity-linking graduates to their BalletArtists records
(`docs/eval/known_issues.md` #34, seventh addendum) — a reminder that an
"agrees/disagrees" check is only as good as the date it's checking
against, and a named-exception sentence attached to the wrong row (or,
here, parsed for the wrong clause) can look exactly like a genuine
cross-document discrepancy until read directly.

## What this means for research use

These aren't data-quality problems to fix — the database's `raw` schema
already captures these entries correctly, verbatim. They're a substantive
finding about the source: the Imperial Theatres' own administrative
publication contains internal arithmetic inconsistencies in at least some
performance tallies. Worth keeping in mind before treating any single
printed "Всего" figure as ground truth without cross-checking its own
listed components — the yearbook's arithmetic is not always self-consistent,
independent of anything this pipeline did.

Not yet known: whether this is evenly distributed, concentrated in
particular seasons/pages, or specific to certain preparers/printers. Revisit
once the full `credit_sum_mismatch` review (currently in progress, see
`credit_mismatch_review.csv`) is complete — with enough confirmed cases,
that question becomes answerable.
