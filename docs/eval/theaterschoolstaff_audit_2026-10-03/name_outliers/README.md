# TheaterSchoolStaff: single-season name outliers checked on the scan (2026-10-05)

**Why.** The 22-page blind sample found 5 surname errors in 625 rows; 77 pages were not sampled. The cheapest way to surface the unsampled misreads is the same one that found most of the genre-queue bugs: an entry whose spelling differs by a small edit from the person's majority spelling in >= 3 other seasons.

**Method.** For every TheaterSchoolStaff person with >= 4 entries, family/first/patronymic values that occur in <= 2 entries but are >= 70% similar to a spelling shared by >= 3 other entries: 53 candidates; 5 were on the sampled pages (already read blind); the other **48 were read blind on the scan by three readers** (zoomed crops, no stored value shown; `reader_results/`, `items.json` has stored and majority values).

**Result.** 38 print exactly as stored (genuine print variants: Михаиловичъ in 1907-08, Банковскій vs Бонковскій, Капыловъ vs Копыловъ, Потѣхннъ, Всеволожскій/-ой, Владимиръ without і, ...); **9 print the majority spelling, so the stored value was a misread**, corrected (`apply_name_fixes.py`, old-value assertions, backup `..._2026-10-05_name_outliers`, rebuilt, all invariants unchanged): Филотовичъ->Филотеровичъ (1898-99 p001), Зацімовскій->Зацимовскій (1908-09 p002), Анемполистовичъ->Анемподистовичъ (1897-98 p003), Рофасть->Рофастъ (1893-94 p003), Мирониковъ->Миронниковъ (1901-02 p000), Семеничковъ->Семенчиковъ (1900-01 p001), Легать 1-й/2-й->Легатъ 1-й/2-й (1902-03 p001, hard sign), Полієвктовъ->Поліевктовъ (1902-03 p002, a stray Ukrainian є). The one item the stored value shares with the print and the majority does not ("Геогрій", 1909-10 p004, confirmed at 8x) is a genuine print typo, listed in genuine_print_typos.md.

**Yield.** 9 errors from 48 reads (19%) -- the worklist is far richer than random sampling (0.8%). The method only sees misreads that are inconsistent with the same person's other seasons; a misread present in every season of a person, or in a person with < 4 entries, would not show.

**Follow-ups noticed.** (1) The soft/hard-sign confusion in Легатъ is not confined to the school lists: BalletArtists stores 41 "Легать" against 33 "Легатъ" (and Graduates 1 vs 2) -- every scan read of this surname so far prints the hard sign; a blind read of those entries is the natural next check. (2) "Головань" (ь) is stored in 3 seasons and "Голованъ" (ъ) in 1; checked on the scan, see the addendum in known_issues.md.
