# TheaterSchoolStaff: two-pass blind re-read of the SECTION structure (2026-10-05)

**Why.** The school-level continuation error (1898-99 p003/p004, see ../blind_headings/) happens one level down too: a continuation page prints no heading for the section it continues ("а) Балетное отдѣленіе", "б) Драматическіе курсы", "Классныя дамы", the preparatory-class lists), so a page-local read cannot verify the section of its top rows.

**Method.** Every one of the 99 pages was mapped TWICE by independent report-only readers (pass C: pages interleaved over 5 readers; pass D: 5 different readers on consecutive blocks; `PROMPT.md`, `partitions.json`, raw output in `reader_results/`). Per page the reader lists every printed section heading and, under it, every entry (list number + surname) in print order, marking entries at a column top whose heading is on an earlier page/column as CONTINUED. They saw only the scan. `compare_sections.py` / `cross.py` match each printed row to the stored row (family-name prefix + list number), carry the section forward across columns and pages (two-block pages with a mid-page school heading handled), and compare with the stored section path (similarity >= 0.8 so heading wording variants like Учители/Учителя are not errors).

**Result.** 2,742 (pass C) and 2,739 (pass D) printed rows matched to stored rows; **2,734 rows are confirmed by both passes and the stored data; no row is wrong in both passes** (section assignments: 0 errors beyond the already-fixed 1898-99 pages). The 3 rows where exactly one pass disagrees are reader artefacts on 1901-02 p002 (a mixed page). Unmatched rows are all artefacts (a reader typing a Ukrainian є or Latin i, note text appended to a surname, one reader's "Брюннеръ" for Бруннеръ). No printed row is missing from the stored data and no stored row is absent from the print. The one genuinely ambiguous placement, Сперанскій on 1896-97 p000 (unnumbered at the top of the right column, no heading above him; the new deacon replacing Флоринскій "Оставилъ службу 1 февраля 1897 г."), is stored as Дьяконъ, which is consistent with the print and his later years.

**Byproduct: a free second blind read of every surname.** Where both passes read the same spelling and it differs from stored: 7 rows. Blind high-zoom reads of the word endings (`hardsign_check/`): **Маннъ x3 (1890-91 p000, 1892-93 p000, 1894-95 p000) and Тернизьенъ x3 (1891-92 p002, 1893-94 p001, 1894-95 p001) print the hard sign** -- the stored "Маннь"/"Тернизьень" were misreads, corrected (`apply_surname_fixes.py`, backup `..._2026-10-05_sections_surnames`); **Потѣхннъ (1892-93 p000) is confirmed a genuine print typo** (two plain н, no и diagonal; kept, in genuine_print_typos.md); Головань with the soft sign in 3 seasons stays (checked glyph by glyph earlier: the print has ь).

**Net.** The structure of the TheaterSchoolStaff lists (school, section, row membership, row set) is now independently confirmed on all 99 pages by two blind reads, apart from the one error already fixed (1898-99) and 6 surname misreads fixed here.
