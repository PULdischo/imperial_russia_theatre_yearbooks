# Homonym sweep (wrongly merged persons) -- 2026-10-05

**Method** (`signal_scan.py`, `timeline.py`): for every live person, look at the linked entries across seasons and compute signals: conflicting patronymics (after normalising ѳ/ф, і/и/ѣ/е, word endings), conflicting first names, conflicting start dates, entries after a recorded death/leaving date with no rehire evidence, the same person in both cities in one season, implausible list-type combinations, instrument-family changes. Every candidate was read as a full timeline; doubtful ones were checked on the scan (report-only readers on zoomed crops).
