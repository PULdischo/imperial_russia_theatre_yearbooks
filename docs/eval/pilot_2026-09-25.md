# 200-page pilot, 2026-09-25

`review_system_lines.txt`, temperature 0, three passes. Page list:
`outputs/reviews/pilot200.txt` (seeded, reproducible). Stratified across all
41 season/city/genre groups and all 17 seasons: 132 ballet, 46 opera, 22
combined; 127 SP, 73 Moscow.

**600 calls, zero API failures.**

## Text capture — no systematic loss

285,849 characters over 200 pages, median page 1,413. Nineteen pages under
200 characters are all genuine **full-page plates**, verified against the
scans: e.g. `review_1899-00_SP_ballet_p022` is a colour illustration whose
only text is `Théâtre de l'Hermitage`, and the model returned exactly that.

**~10% of the corpus is plate pages**, which the gold set barely represents
(one of twelve). They account for the `no_folio` and `thin_page` flags and
for both folio errors below, so flag counts at full scale will look alarming
unless this is expected.

## Folio integrity — 2 errors in 200 (1%), both caught without gold

Corrections in `docs/review_folio_corrections.csv`; both verified against
the scans at full resolution.

| page | model | truth |
|---|---|---|
| `1902-03_MSK_ballet_p002` | `19` | **no folio** — a rotated full-page plate with a vertical caption. The number was FABRICATED, most likely from `Актъ I. Картина II`. |
| `1903-04_SP_ballet_p012` | `16` | **116** — the leading 1 is damaged to a colon-like mark, so the leaf reads `:16`. Confirmed from both sides (idx 10 = 114, idx 13 = 117). |

The first is the failure class to watch: **fabrication, not misreading**. The
page looks perfectly normal in isolation and only the sequence check
surfaces it.

## Two problems the pilot found that were not on the list

**A JSON homoglyph.** One response in 600 was unparseable: the model wrote
`съ\нимъ` for `съ\nнимъ` — Cyrillic `н` in place of Latin `n` *inside the
escape sequence*. Left alone it costs the whole page; at ~1 in 600 that is
roughly five pages of a 3,072-call full run. `parse_reviews.py` now repairs
it and logs `CHECK THIS PAGE`.

**The folio check fired on non-adjacent pages.** It compared each folio with
the previous one *seen*, assuming everything between was present. On a
sample it is not — it reported `194 -> 117` as a missing page when the two
were nine scan pages apart. Fixed: gaps are only checked when every
intervening scan page is accounted for, otherwise `folio_gap_unverifiable`.
This matters on the full run too, where a render failure leaves the same
hole.

## Run-to-run disagreement — the review burden

Content stability = fraction of run-1 words that both other runs also
produced, with line breaks and block boundaries ignored so the measure is
about *words*, not layout.

    median 0.9817      fully stable pages: 38/199

| threshold | flagged | ≈ of 1,024 |
|---|---|---|
| < 0.99 | 65% | ~660 |
| < 0.98 | 46% | ~470 |
| **< 0.95** | **19%** | **~190** |
| < 0.90 | 7% | ~72 |

**Recommended: < 0.95, ~190 pages.** Below that real breakage is missed;
above it the list fills with line-break wobble.

Only **9 pages** show a run dropping text (>5% word-count spread), and most
are short pages where one word is a large fraction.

**Instability concentrates on SHORT pages** — captions and plates. A
length-aware threshold would rank better than a flat one; not yet built.

## How the review is to be done (agreed with RG, 2026-09-25)

The signal points at *specific passages*, not whole pages, so this is "the
three runs disagree here, here is the scan" — not re-reading 190 pages.

1. **Claude triages all flagged pages.** Most disagreements are line breaks
   and block boundaries: resolve, fix, and log what was done.
2. **Claude surfaces only the residue** — genuine character disagreements on
   damaged or ambiguous type — with image crops, as in the gold workflow.
3. **RG rules on those.** Expected to be a few dozen spots, not 190 pages.

Claude does not get the last word on ambiguous pre-reform orthography. On
the gold set RG corrected confident readings of `Карльсонъ` (soft sign), a
colon read as a semicolon, a fita read as an ef, a comma read as a period,
and a spurious space. See `never-assume-spelling-consistency`.
