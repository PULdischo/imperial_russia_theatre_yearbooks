# Close reads

Line-by-line diplomatic transcriptions of single RGIA pages whose page-triage summary
(docs/rgia/dela/<delo>.jsonl) was too uncertain for the page's importance. One file per
page (or per sheet photographed twice), named <delo>_p<PDF page>.md. Conventions:
pre-reform orthography verbatim; [зачеркнуто: …], [надъ строкой: …], trailing "?" for a
doubtful word, [нрзб] for an unread one; figures reported as written, with arithmetic
discrepancies noted separately.

These are finding aids, "checked by Claude", for RG to read against the source. When a
close read corrects a triage summary, the summary is updated and points here.
