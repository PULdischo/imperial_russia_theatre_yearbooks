# Д. 163, л. 37 (PDF p. 68) — close read, checked by Claude 2026-11-24

Order to deduct 20 р. for issues bought, November–December. Calligraphic clerk's hand; folio «37»; no number or
stamp visible; undated. The whole sheet is crossed through with one large diagonal stroke.

```
                                                    Въ Счетное Отдѣленіе
Слѣдуетъ удержать 20 руб. съ нижепоимено-
ванныхъ лицъ изъ получаемаго ими содержанія
за пріобрѣтенныя изданія „Ежегодника Импера-
торскихъ Театровъ"

                          Фамиліи                въ Ноябрѣ  въ Декабрѣ  Всего
По драмѣ:            съ Яковлева Степ.            1р.        1р.        2р.
По балету:            " Ѳедорова IIго             1-         1-         2-
                      " Чекрыгина Iго             1-         1-         2-
                      " Тихомірова Iго            1-         1-         2-
По оркестру           " Е[…]кина?               [³]2-        2-         4-
По декораціон. ч.   ✓ " Максимова, пом. дек.      1-         1-         2-
                    ✓ " [Т/Ш]айенскаго?           2-         2-         4-
По Управленію         " Бартн[о/е]вскаго          1-         1-         2-
                                                  10р.       10р.       20р.
              Всего двадцать рублей
        Редакторъ Ежегодника
        Императорскихъ Театровъ [signature, нрзб]
```

Arithmetic: 1 + 1 + 1 + 1 + 2 + 1 + 2 + 1 = 10 р. per month ✓; 20 р. ✓.

Notes:
- **«Бартн[о/е]вскаго» «По Управленію»:** the second-to-last row is a deduction of 2 р. from a man in the Контора's
  administration; the fifth letter is «о» or «е». The printed Roster has «Бартновскій, Петръ Осиповичъ» (query logged
  2026-11-24). He is the likely signer of the «За редактора» orders on pp. 60–65 (see `163_p061-062.md`); RG's decision.
- The orchestra row has a small «3» written before the «2» of November, perhaps an overwritten figure.
- Ballet Roster matches (SP 1903-04/1904-05; identity not decided): Ѳедоровъ 2-й, Леонидъ Ивановичъ; Чекрыгинъ 1-й,
  Иванъ Ивановичъ; Тихоміровъ 1-й, Сергѣй Михайловичъ.
- The year is not written. The crossed-through text at the top of p. 66 («за пріобрѣтенныя изданія…») matches this
  order's wording, so this sheet probably lay above л. 36 when photographed.
